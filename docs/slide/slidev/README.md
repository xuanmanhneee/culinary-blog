# Slide báo cáo (Slidev)

Chạy trong thư mục này:

```
pnpm install
pnpm dev          # xem và trình chiếu tại http://localhost:3030 (phím P: chế độ trình bày, có ghi chú)
pnpm build        # xuất bản web tĩnh vào dist/
pnpm export       # xuất PDF (cần playwright-chromium)
```

- Nội dung: `slides.md` (ghi chú nói nằm trong `<!-- -->` dưới mỗi slide).
- Giao diện: `style.css`, chân trang: `global-bottom.vue`, ảnh: `public/img/`.
